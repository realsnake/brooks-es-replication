# Brooks ES 策略规格 v1 修正案（只改一处：开盘段档的 RR 门目标口径）

日期：2026-11-12（北京时间）。状态：**已落定，随引擎 v4.1 生效**。本修正案只含一处变更，其余全部条文沿用规格 v0 冻结版（`brooks-strategy-spec-v0-frozen-2026-11-12.md`，含草案 54 条与 F1–F9），不重述、不改动。

## 2. 变更内容（全文，仅此一条）

自 v1 起，对**符合 v0 冻结 F2 开盘段档启用条件的 S3 候选**（setup 为 S3、信号 bar ≤ bar 12、按正常档公式张数 <1、止损距 ≤60 点），其放行盈亏比门（RR ≥ 0.75）的**目标距离改按 measured move（MM）口径计算**，不再使用最近关键价位距离：

- **MM 距离（确定性定义，规格与代码同义，见 §3）**：取触发该 S3 的信号序列的位移幅度——序列最高价 − 序列最低价。
- **MM 目标价**：入场价沿顺势方向投影一个 MM 距离（做多 = 入场价 + MM 距离；做空 = 入场价 − MM 距离）。该目标价只作 RR 门的判定量记录（S3 出场机制仍为冻结 F6 的滚动线，目标价不是出场价位，与 v4 口径一致）。
- **RR** = MM 距离 / 止损距，门槛不变，仍须 ≥ 0.75 才放行；不足仍否决。
- **适用范围之外一律不变**：非开盘段 S3（正常档）的 RR 门与目标口径维持 v0/v4 原样（最近关键价位、RR ≥ 0.75）；S1/S2 的目标口径不变（且在 v4 起仅作 shadow 记录）；F2–F4 的档位启用条件、上限（$300 / 1 张 / 止损距 ≤60 点）、单独记账要求全部不变；「禁止收紧止损凑张数」不变。

## 3. MM 的确定性定义（与引擎 v4.1 代码逐字对应）

- **信号序列**：引擎在生成该 S3 候选时构造入场价与止损价所用的同一组 bar——自发起 Always In 翻转的强 bar（序列首 bar）起、至决策 bar（翻转确认的那根 bar）止的全部 bar（引擎 `setups_at_close` 中的 `seq = self.bars[first_bar - 1:]`，入场 = 序列顺势极值外 0.25、止损 = 序列逆势极值外 0.25）。
- **MM 距离** = 序列最高价 − 序列最低价（`max(x["h"] for x in seq) - min(x["l"] for x in seq)`，在 `setups_at_close` 中记为 `mm_amp`，经 `try_create_pending` 的 `mm_dist` 参数传入 `pick_target` 判定）。只用决策时点已收盘的 bar 计算，无未来数据。
- 注记（定义的结构性后果，如实登记）：因入场/止损同由该序列极值 ±0.25 构造，止损距恒等于 MM 距离 + 0.5 点，故本口径下开盘段候选的 RR 恒在略低于 1.0 的水平（= MM 距离 / (MM 距离 + 0.5)），只要序列位移 ≥ 1.5 点即过 0.75 门。这不是放水或私改：它正是师父开盘单的风险结构——止损放在 spike 起点外、目标取 spike 幅度的一倍投影，风险与目标同源。开盘单真正的过滤仍由其余各门承担（日型、AI 确认与语境门、位置门、最小止损 8 点、止损距 ≤60 点、每日 1 笔）。

## 4. 证据锚

1. **条文张力（训练集原型）**：v4 编码自检发现，训练集唯一的开盘段原型——2026-11-05 bar2 的 S3 空头候选（止损距 56.25 点）在 v0 原口径下按最近关键价位（7650）算 RR 只有 **0.12**，被 RR 门否决（v4 编码报告 §4、§6-1）。开盘宽止损 S3 的最近关键价位天然贴近入场、止损又宽，此口径下该档几乎必然零成交，F2–F4 的档位设计（源自用户 U1 选 (b) 的决定）将被另一道门架空。
2. **师父的开盘单目标口径本就是 measured move**：S3 批改报告（`brooks-s3-grading-and-spec-notes-2026-11-11.md`）对 2026-11-05 的登记——1105-oral-02（bar3）：跟随确认后顺势卖出、止损放 bar1 上方、**目标为 measured move**（原文 "hold for measured move down"）；批改 §①A-4 亦注明师父开盘空单的目标口径是 measured move、无点位条目落到引擎的最近关键价位目标。即：对开盘顺势单，师父从不用「最近关键价位」量目标，v0 的统一口径与师父在这一档上的实际口径不一致，本修正是把这一档的量法改回师父的量法，不是新发明规则。
