## 1. 变更（只一处）

自 v4.1 起，**开盘段档候选**（S3、信号 bar≤12、正常档张数 <1、止损距 ≤60 点，即 v4 判定 tier="opening" 的那一档）的放行盈亏比门，目标距离改按 measured move 口径；其余情形（正常档 S3、S1、S2）与 v4 逐字相同。

**MM 定义（与规格 v1 §3、变更日志逐字对应）**：MM 距离 = 触发该 S3 的信号序列的位移幅度 = **序列最高价 − 序列最低价**；「序列」是引擎构造该 S3 入场/止损所用的同一组 bar（自发起 Always In 翻转的强 bar 起、至决策 bar 止）。MM 目标价 = 入场价 + 方向 × MM 距离；RR = MM 距离 / 止损距，门槛仍为 ≥0.75。

代码位置：`setups_at_close` 的 S3 分支以同一 `seq` 变量算 `mm_amp` 并以 `mm_dist` 参数传入 `try_create_pending`；后者仅在 tier 判定为 "opening" 时把 `mm_dist` 转发给 `pick_target`；`pick_target` 在函数体首部对 S3+mm_dist 短路走 MM 口径（不再算关键价位）。v4↔v4.1 全文 diff 已审计：差异只有文件头说明与这三段，无其他门/参数漂移；输出 JSON 无字段增删（开盘段成交的 `target` 字段值改为 MM 投影价，语义仍只是 RR 判定量，S3 出场不使用）。

结构性注记（如实）：入场/止损同由序列极值 ±0.25 构造，止损距恒 = MM 距离 + 0.5，故本口径下开盘段 RR 恒略低于 1.0——这正是师父开盘单的风险结构（止损在 spike 起点外、目标取 spike 幅度一倍投影），规格 v1 §3 已登记；开盘单的实际过滤由其余各门承担。
